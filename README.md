# Bengali NLP: Sentiment & Emotion Analysis

## 📌 Project Overview
End-to-end Bengali NLP project for Sentiment and Emotion 
classification using Classical ML and Deep Learning.

## 📊 Dataset
- 5,917 unique Bengali texts
- 5 Sentiment classes: Negative, Strongly Negative, 
  Neutral, Positive, Strongly Positive
- 5 Emotion classes: Creepy, Bullying, Unbiased, 
  Joyfull, Surprise
